# Thank you

Magnetissimo has been around since 2016, and it was never a one-person
project. People I've mostly never met found it, liked it, and gave it their
evenings: they wrote crawlers, fixed bugs, packaged it for Docker, and
cleaned up typos. None of them owed it anything and doing it pre-AI means a lot!

Each character was typed by hand!

This version is a rewrite, so most of their code is no longer in it. Their
ideas are. Nyaa as a source, magnets built from a bare infohash, a Compose
file that just works, and a design worth looking at all started with someone
on this list.

Thank you, all of you.
